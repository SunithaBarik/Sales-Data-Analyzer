# 📊 Sales Data Analyzer
Exploratory Data Analysis on 1000 rows of retail sales data.

## 🎯 Key Insights
- Total Revenue: ₹2.54 Crore
- Total Profit: ₹50.8 Lakh
- Top City: Mumbai (₹4.60 Crore)
- Best Month: April (₹2.55 Crore)
- Top Products: Tablet, Mobile, Keyboard

## 🛠️ Tech Stack
Python, Pandas, Matplotlib, NumPy, Jupyter Notebook

## 📊 Dashboard
2x2 Dashboard with Product, City, Monthly Trend & Profit Distribution.
